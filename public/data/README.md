# Geography

`east-asia-map-units.geojson` is an extracted subset of **Natural Earth 1:50m Admin 0 – Map Units**.

- Source: <https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-details/>
- Upstream repository: <https://github.com/nvkelso/natural-earth-vector>
- Natural Earth data is in the public domain.
- Extracted actors: China, Hong Kong, Taiwan, North Korea, South Korea, Japan, the United States, and all eleven ASEAN members.

Country names and boundary presentation are used only for scenario navigation. They do not express a position on sovereignty, legal status, or disputed boundaries.
